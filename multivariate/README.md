# M-SpectraCast

Cluster-enhanced multivariate forecasting for frequency-selective RF-EMF and wireless time-series data.

## Structure

```
src/        analysis scripts (heatmaps, continuous-period windows)
datasets/   processed EMF CSVs (UH / ED, by year)
```

UH = University Hospital, ED = Electronic Department. Columns are frequency bands in MHz; each row is a timestamped reading.
